# 新手引导示例：Attention Is All You Need

论文：Ashish Vaswani 等，2017，arXiv:1706.03762。
来源：https://arxiv.org/abs/1706.03762

此目录保存用户提供的本地论文 PDF、已生成的版面解析结果及中文机器译文，供 NeoRead 新手引导离线使用。论文著作权归原作者；机器译文仅供阅读辅助，请以原文为准。

- `paper.pdf`：原始 PDF（15 页）。
- `analysis/`：解析正文、版面索引及图片。已移除本机运行耗时与内存统计。
- `paper.json`：论文公开元信息和 122 条已完成的译文，保留段落编号、原文散列和句子对应关系。

不包含本地数据库、阅读进度、笔记、聊天、个人设置、凭据或模型用量。文档 ID 取 PDF SHA-256 的前 32 个十六进制字符，与普通导入一致。

资源通过 Go embed 随服务端打包。仅在本地书库尚不存在时初始化；已有书库（包括空书库和旧 Reader 书库）不自动导入。删除示例、清空书库或重复运行引导均不会恢复示例。初始化中断后通过专用 pending 标记恢复，已有用户数据不会被覆盖。
