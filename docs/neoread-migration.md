# NeoRead 更名迁移设计

状态：讨论稿。以下流程尚未实现，当前 `legacy-data.ts` 的逐项移动不能作为正式升级方案。

## 已确定的边界

- 老用户手动下载 NeoRead，不兼容旧版自动更新安装包名称。
- Chrome 插件继续连接 Reader 和 NeoRead，保留扩展 ID、端口、鉴权和接口。
- 桌面只注册 `neoread://`；以前复制或导出的 `reader://` 链接需手动替换协议。
- 默认书库复制到 NeoRead 的应用数据目录；外置或自定义书库完整复制到同级新目录。原书库保留，不自动删除。
- 新数据库、锁文件和开发数据目录拟分别命名为 `neoread.sqlite`、`neoread.lock`、`.neoread`。此次名称清理暂未切换这些持久化入口。

## 建议流程

1. **发现与确认。** 读取旧应用的数据位置和 `library-location.json`，展示源书库、目标位置及所需空间。以实际指针为准，不猜测外置目录；外置设备离线时提示连接设备，不创建空书库。已有 NeoRead 书库时不自动合并或覆盖。
2. **停止写入。** 要求旧 Reader 退出，取得旧书库的 `reader.lock` 并持有到复制完成。锁文件在新旧版本间名称不同，迁移器必须显式取得旧锁。NeoRead 迁移期间不启动正常服务或后台 Agent。
3. **准备目标。** 默认目标为 NeoRead 应用数据目录下的 `library`；自定义书库目标建议为同级 `NeoRead Library`。目标存在时让用户选择其他新目录，不自动追加编号或覆盖。检查可用空间并预留复制、数据库快照和校验空间；文件系统拒绝写入时仍必须安全失败。
4. **复制到临时目录。** 临时目录与最终目标在同一文件系统，使用本次迁移的唯一 ID 和清单标记。完整复制原文、附件、笔记相关文件和持久化数据，保留相对路径。排除旧锁、`server.json` 和明确可重建的临时运行文件；遇到符号链接或特殊文件停止并说明，不跟随链接复制未知目录。
5. **生成数据库快照。** 通过 SQLite 备份接口或经验证的等价快照方式生成 `neoread.sqlite`，包含 WAL 中已提交的数据。避免直接把尚有 WAL 的数据库主文件单独改名。若选用现有复制逻辑，应先在临时副本恢复 WAL，再关闭数据库并生成最终快照，不更改旧库。
6. **迁移路径和设置。** 沿用现有 `relocateCorpusFingerprints` 的处理，更新依赖书库绝对路径的索引指纹；检查文档路径、AI 会话工作目录和缓存引用。迁移数据库中的旧品牌设置键，以及新版改名后的浏览器偏好键。只转换已定义字段，不对用户笔记、聊天、文件内容进行全局替换。
7. **验证。** 校验 SQLite 完整性、必要表、文档/批注/聊天等关键记录数量和外键；对复制文件核对清单、大小及哈希。确认 PDF/EPUB 路径有效，原文、阅读位置、译文、笔记和聊天均可读取。源目录存在已缺失文件时明确报告，不能误报完整迁移。
8. **启用。** 先将临时目录原子改名为最终目录，再原子写入 NeoRead 的书库位置和完成记录。写入顺序必须允许崩溃恢复；完成记录包含源路径、目标路径和迁移版本。同步文件及目录元数据后再启动服务。启用后只写新目录。

## 中断与恢复

记录 `prepared → copying → verified → installed → activated` 状态，不能仅因目标出现 `library` 就视为成功。重启后从清单确认本任务拥有的临时目录；首版建议重新复制未验证副本，避免实现未经验证的按文件断点续传。目标已安装、指针未写入时，重新验证后完成启用，不再复制第二份。

复制、校验或指针写入失败时显示具体阶段，不静默启动空书库。仅清理清单证明属于本次迁移的临时文件。原书库不删除，空间不足也不通过删除原文件腾出空间。保留旧库意味着用户重新运行旧 Reader 后可能产生两套不同的数据，界面和升级说明需明确这一点；不做自动双向合并。

## 发布前验收

- 默认及外置书库，包含非空 WAL、批注、译文、聊天、代理设置和插件配对。
- 旧应用运行、目标冲突、空间不足、文件权限不足、设备中途断开。
- 每个状态转换前后强制中断，重新启动后恢复或明确失败；原库仍可打开。
- 新旧命令入口、macOS 应用并存、Windows 安装条目、插件连接新旧应用。
- 不再接受旧桌面协议；新复制链接和批注 Markdown 链接可定位。

## 新签名证书

NeoRead 使用新的 `NeoRead Self-Signed` 证书，Actions 读取 `NEOREAD_MAC_SIGN_P12` 和 `NEOREAD_MAC_SIGN_P12_PASSWORD`。旧 secrets 保留供旧版本流程使用。更换证书的首版通过手动安装交付；之后的 NeoRead 发布持续使用同一张证书。
