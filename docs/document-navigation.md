# 目录与书签

Reader 将文件目录、正文解析标题和个人书签显示在同一棵导航树中。目录项与书签有独立类型，书签显示图标；层级与类型互不绑定。右键可以改名、恢复原名、切换类型、提升一级或移入前一个符合条件的目录；F2 开始改名，Enter 保存，Esc 取消。箭头只展开或收起，标题用于跳转。

PDF 优先读取原文件 Outline。没有 Outline 时使用已解析的 `doc_title`、`paragraph_title` 块；没有标题时保留只读页码列表。解析完成后自动更新。标题生成依赖版面模型，模型漏识别的标题不会自动补齐；可以在该处添加书签，再转为目录项。

## 顺序与层级

整棵树的先序遍历必须与原文顺序一致，折叠只影响显示。拖动条目时带上全部子项，只改变父级；不允许循环、父级在子项之后、子树跨过其他章节等冲突。右键移动遵循同一规则。

PDF 使用页码、解析块的阅读顺序、块内位置排列，支持双栏内容。Outline 保留 XYZ 等目标的页内坐标；只有页码的目标尝试匹配同页唯一标题，无法匹配时保留原始条目顺序。没有足够信息时，无法从仅有的页码还原真实页内位置。EPUB 使用 spine 阅读顺序与正文锚点/文本位置，屏幕分页不参与排序；无法解析 EPUB 顺序时禁止调整层级。

个人书签默认与其之前最近的目录项同级。如果位置在父标题和首个子标题之间，同级插入会破坏全局顺序，此时放在该父目录内。显式调整过父级的书签保留用户指定的关系。恰好相同的目标位置使用来源的稳定顺序打破平局。

## 保存与恢复

`document_navigation` 表保存每篇文档的名称、类型、父级和折叠覆盖值，不修改原文件。GET/PUT `/api/documents/{id}/navigation` 使用 revision 防止多窗口互相覆盖。个人书签的原始定位继续保存在 annotations 中。

解析生成的标题以页码、规范化原始标题的散列和同名出现次序标识，避免重解析导致段落编号变化后错用改名。失去匹配的覆盖记录仍保留；不会把它转移给其他标题。新的解析结果若使旧层级不满足原文顺序，显示时将冲突项提升，保留已保存的编辑供再次匹配。

## PDF 导出与重导入

所有 PDF 导出入口包含当前目录、书签和选中的文本批注。即使没有文本批注，也可以导出目录。译文批注仍不写入原文。

导出副本写入标准 Outline 的标题、父子关系及目标位置，同时在 PDF Info 的 `ReaderNavigation` 字段保存版本 1 的类型清单（ID、类型、原名、当前名称及目标位置）。这不是加密数据；与普通目录一样随文件分享。

Reader 重新读取时，逐项核对清单数量、唯一 ID、标准 Outline 的标题及位置。完整匹配才恢复类型；缺失、损坏或过期的标记退回普通目录。标记不提供可执行动作或新的跳转目标。第三方阅读器仍可读取标准 Outline，但不保证区分 Reader 的两种类型。其他软件清除私有元数据后，类型区分可能丢失。

PDF.js 负责读取和批注写入；pdf-lib 按需加载，随后写出包含 Outline 的完整副本。原文件保持不变。EPUB 支持书库内的目录编辑，本功能不增加 EPUB 文件导出。

## 验证

自动测试覆盖全局顺序与循环限制、双栏与同页顺序、目录/书签关系、重解析稳定 ID、EPUB spine 与锚点、保存冲突及重启读取、折叠与跳转分离、右键改名的焦点，以及 PDF 中文标题/类型/层级/高亮/旋转裁剪页面的往返。

人工验收：检查箭头居中和动画；拖放符合顺序与冲突的条目；改名后重新打开文档；添加个人书签并验证层级；导出 PDF 后在新文档中确认类型和跳转。视觉验收不使用浏览器自动化。

## 多选与删除

左下角复选框按钮进入多选；点击条目切换选择。Command（Windows/Linux 为 Ctrl）点击可直接进入多选，Shift 点击按当前展开的可见条目选择连续范围，Command/Ctrl + Shift 可追加范围。Esc 或取消按钮退出。

批量删除用一次带版本号的导航保存请求写入 `deleted: true`。只移除选中导航条目，未选中的后代提升到最近保留的父级，原文顺序保持不变。原文和底层批注保留；删除的导航条目不再显示，也不进入 PDF 导出目录。保存失败时保留选择并重新读取服务端版本。
