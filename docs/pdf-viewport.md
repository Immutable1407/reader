# PDF 缩放与视口适配

每份 PDF 分别记住手动缩放比例。切换原文与双语模式、调整分栏或侧栏时，PDF 随可用宽度等比缩放，并尽量保持视口中央的阅读内容及横向位置。自动适配和段落聚焦不会覆盖手动缩放偏好；“适合宽度”模式继续贴合栏宽。

拖动分栏或侧栏期间保持 PDF 比例，释放指针或调整键后再适配最终宽度；侧栏展开与收起等待布局动画结束。窗口连续调整尺寸时，等待尺寸稳定 120ms 后适配。最终只更新一次 PDF.js 缩放，使用 160ms 的视觉过渡，开启系统“减少动态效果”时跳过过渡。新输入会取消尚未完成的视觉过渡。

## 人工验收

1. 为两份 PDF 设置不同的缩放，分别重开并重启应用，确认各自恢复。
2. 打开双语模式，拖动分栏和两侧栏，再恢复原宽度，确认阅读中心与横向位置没有持续偏移。
3. 聚焦段落后调整分栏，确认自动适配不覆盖手动缩放；重开后恢复手动偏好。
4. 对没有解析段落的 PDF 检查相同行为，再检查“适合宽度”模式能持续适配。

5. 拖动两侧栏及双语分隔条，按住并停顿，再松手：拖动与停顿期间比例不变，松手后只缩放一次。长按方向键调整分栏后松键，检查相同结果。
6. 快速连续展开、收起两侧栏：布局稳定后缩放一次，阅读位置不持续偏移。分别检查数字缩放和“适合宽度”。
7. 开启“减少动态效果”后重复检查；调整过程中切换文档、关闭阅读标签，确认没有残留缩放。
